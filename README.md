# 볼더링 복귀 트래커

볼더링 트레이닝(4주 단위 진행표 + 식단)을 매일 따라가기 위한 모바일 웹앱입니다. 자연 바위 기준 **V0~V10 레벨**(또는 더클라임·웨이브락 색 기준)을 고르면 문제 난이도, 행보드, 풀업, 록오프, 집 운동 변형과 횟수가 그 레벨에 맞게 바뀝니다.

**앱 주소: https://kaya1914-blip.github.io/boulder-tracker/**

- **레벨**: V0~V10 등급마다 처방이 따로 있습니다(세션 시간, 한계·볼륨·지구력 방식, 행보드 그립·무게·세트, 풀업 진행, 록오프, 캠퍼스, 코어, 기술 드릴, 집 운동 횟수). 큰 묶음은 V0~1 입문 · V2~3 초급 · V4~5 중급 · V6~7 중상급 · V8~10 상급. 오늘 화면(처음 한 번)과 설정에서 고릅니다.
- **오늘**: 요일 고정이 아니라 **회복 기반**으로 추천합니다. 운동 후 "운동량" 카드에 실제 시간과 힘든 정도(RPE)를 적으면, 손가락을 많이 쓴 다음 날은 손가락 안 쓰는 집 운동/휴식, 고강도는 48시간 간격, 3일 연속이면 휴식, 최근 7일 부하가 평소의 1.5배를 넘으면 가볍게 갑니다. 주차에 맞춘 체크리스트, 단계별 포커스 모드, 그날 식단을 보여줍니다. 이번 주 준비·장보기 카드는 매일 보이고 접어 둘 수 있습니다.
- **유형**: 입문 · 복귀 · 레벨업 중 고르면 첫 주 강도와 쉬는 규칙이 달라집니다(입문은 이틀 연속 암장 금지, 복귀는 1주차 볼륨·2주간 행보드 한 단계 낮춤).
- **컨디션 점수**: 수면·통증·근육통·어제 운동량·연속 운동·7일 부하를 합친 0~100점. 오늘 추천에 반영됩니다.
- **몸 상태 정도**: 손가락·팔꿈치 통증, 근육통, 아픔(감기·장염)은 **조금 · 중간 · 많이**로 고릅니다. 조금은 고강도만 막고(손가락 조금이면 볼륨 가능, 아픔 조금이면 가벼운 운동), 중간 이상은 손가락 운동·운동 자체를 쉬게 합니다. 예전 기록의 "있음"은 중간으로 봅니다.
- **자연 바위**: 지역·문제·등급·플래시/완등/프로젝트·시도 횟수를 기록하고 등급 피라미드로 봅니다.
- **체력 측정**: 20mm 행보드 10초 최대 무게와 무게 풀업(또는 맨몸 횟수)을 체중 대비 %로 바꿔 힘 기준 예상 등급을 계산하고, 실제 완등 등급과 비교해 힘과 기술 중 무엇이 부족한지 알려줍니다. 인바디(체지방률·골격근량·기초대사량)를 넣으면 칼로리 계산과 체성분 분석에 쓰입니다.
- **데이터 보호**: 영구 저장 요청, 하루 한 번 자동 스냅샷(14일, 되돌리기 가능), 백업 파일 바로 보내기.
- **뒤로가기**: 폰 뒤로가기 버튼이 시트·화면을 하나씩 닫고, 오늘 화면에서만 앱을 닫습니다.
- **기록**: 아침 체중, 수면, 통증, 볼륨 완등 개수, 한계 문제 도달 홀드, 행보드 단계, 풀업 횟수를 적습니다.
- **타이머**: 행보드(비스트메이커 1000/2000 그립), 휴식, 인터벌, 그리고 집 운동용 **템포 카운터**(한 회의 박자를 초마다 소리로, 횟수를 음성으로 세고 세트 휴식까지 이어서 진행). 소리·음성·진동 안내, 화면 꺼짐 방지.
- **주간**: 체중 그래프(7일 평균, 목표선)와 조정 규칙 자동 판정, 다음 주 권장사항, Claude 주간 분석 리포트 내보내기.
- **설정**: 레벨, 내 정보(성별·나이·키), 체중 목표(감량·유지·증량), 식단 목표(비우면 기초대사량으로 자동 계산, 직접 지정도 가능), 라이트/다크 테마, JSON 백업 내보내기/불러오기.
- **식단**: 음식 약 890개(디저트·국·반찬·조림 포함). 음식을 누르면 "담는 중"에 들어가고 −/+(0.5인분 단위)·✕로 고친 뒤 **완료**를 눌러야 끼니에 들어갑니다. 목록에 없는 음식은 이름이나 재료("밥 1공기, 계란 2개, 스팸 50g")를 넣으면 음식 DB로 칼로리·단백질을 계산해 내 음식으로 저장합니다. 끼니에 담긴 음식도 −/+ 0.5인분과 삭제 버튼. 자주 먹는 음식 묶음을 "조합 저장"으로 등록하고 "내 조합"에서 한 번에 불러옵니다. 내 칼로리 목표에 맞춰 끼니 추천의 밥 양이 늘거나 줄고, 주간 체중 추세에 따라 목표별로 조정합니다. 암장 날은 퇴근 후 운동하는 회사원 기준이라 운동 전 간식 대신 **점심 든든히 + 운동 중 마시는 것(스포츠음료·두유) + 운동 직후 단백질 음료**로 짭니다. 단백질 목표는 감량 1.5g/kg(유지 1.3 · 증량 1.6)이고, 지난주가 많이 모자라면 "지난주 평균 + 20g"부터 단계적으로 안내합니다.
- **회사 급식 (선택)**: 설정 → 회사 급식에서 켜고 주간 메뉴를 붙여넣으면(`월: 물만두국, 제육볶음 280/18, 참나물무침`) 그날 점심 추천이 급식 메뉴로 바뀝니다. 숫자(칼로리/단백질)를 안 쓰면 반찬 종류(나물·국·고기·생선·튀김 등)로 급식 1인분을 추정하고, 메뉴에 밥이 없으면 1공기를 넣어 그날 밥 양에 맞춥니다. 끄면 지금처럼 직접 입력합니다. 메뉴는 기록과 같이 그 기기에만 저장됩니다.

## 데이터

기록은 서버 없이 **그 기기의 브라우저(localStorage)에만** 저장됩니다. 저장소에는 기록이 올라가지 않습니다.
브라우저 데이터를 지우면 기록도 사라지니, 설정 탭에서 주 1회 백업하세요.

## 계획 수정

회복 규칙(`recovery`), 클라이머 유형(`tracks`), 근력 등급표(`bench`), 자연 바위 지역(`crags`), 운동 단계, 등급별 처방(`levels`), 단계 묶음(`tiers`), 집 운동 변형(`variants`·`levelVariants`), 진행표, 식단, 저녁 메뉴는 모두 `plan.js`에 있습니다. 이 파일만 고치면 됩니다.

## 폰에서 쓰기 (GitHub Pages)

1. 위 주소를 폰 브라우저에서 엽니다.
2. "홈 화면에 추가"를 누르면 앱처럼 열리고, 오프라인에서도 열립니다.
3. 이 저장소에 변경을 올리면 1~2분 뒤 자동으로 반영됩니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다.

## 파일 구성

- `plan.js` — 프로그램 데이터와 규칙 숫자 (코치 검수 대상)
- `engine.js` — 회복·컨디션 점수·오늘 추천·체력 평가 계산 (화면 없음)
- `app.js` — 화면과 기록 · `food.js` / `foods.js` — 식단과 음식 DB · `pro.js` — 자연 바위·체력 측정·데이터 보호·바코드·뒤로가기 · `timer.js`, `guide.js`
- `tests.html` — 엔진 검사. 규칙을 고친 뒤 http://localhost:8765/tests.html 을 열어 모두 ✓인지 확인합니다. 실제 기록은 건드리지 않습니다.
