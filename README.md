# 볼더링 복귀 트래커

볼더링 트레이닝(4주 단위 진행표 + 식단)을 매일 따라가기 위한 모바일 웹앱입니다. 자연 바위 기준 **V0~V10 레벨**(또는 더클라임·웨이브락 색 기준)을 고르면 문제 난이도, 행보드, 풀업, 록오프, 집 운동 변형과 횟수가 그 레벨에 맞게 바뀝니다.

**앱 주소: https://kaya1914-blip.github.io/boulder-tracker/**

- **레벨**: V0~V10 등급마다 처방이 따로 있습니다(세션 시간, 한계·볼륨·지구력 방식, 행보드 그립·무게·세트, 풀업 진행, 록오프, 캠퍼스, 코어, 기술 드릴, 집 운동 횟수). 큰 묶음은 V0~1 입문 · V2~3 초급 · V4~5 중급 · V6~7 중상급 · V8~10 상급. 오늘 화면(처음 한 번)과 설정에서 고릅니다.
- **오늘**: 이번 주에 남은 세션 중 오늘 할 것을 추천합니다(요일 자유, 고강도 연속 방지). 주차에 맞춘 체크리스트, 단계별 포커스 모드, 그날 식단을 보여줍니다. 이번 주 준비·장보기 카드는 매일 보이고 접어 둘 수 있습니다.
- **기록**: 아침 체중, 수면, 통증, 볼륨 완등 개수, 한계 문제 도달 홀드, 행보드 단계, 풀업 횟수를 적습니다.
- **타이머**: 행보드(비스트메이커 1000/2000 그립), 휴식, 인터벌, 그리고 집 운동용 **템포 카운터**(한 회의 박자를 초마다 소리로, 횟수를 음성으로 세고 세트 휴식까지 이어서 진행). 소리·음성·진동 안내, 화면 꺼짐 방지.
- **주간**: 체중 그래프(7일 평균, 목표선)와 조정 규칙 자동 판정, 다음 주 권장사항, Claude 주간 분석 리포트 내보내기.
- **설정**: 레벨, 내 정보(성별·나이·키), 체중 목표(감량·유지·증량), 식단 목표(비우면 기초대사량으로 자동 계산, 직접 지정도 가능), 라이트/다크 테마, JSON 백업 내보내기/불러오기.
- **식단**: 음식마다 −/+와 삭제 버튼. 자주 먹는 음식 묶음을 "조합 저장"으로 등록하고 "내 조합"에서 한 번에 불러옵니다. 내 칼로리 목표에 맞춰 끼니 추천의 밥 양이 늘거나 줄고, 주간 체중 추세에 따라 목표별로 조정합니다.

## 데이터

기록은 서버 없이 **그 기기의 브라우저(localStorage)에만** 저장됩니다. 저장소에는 기록이 올라가지 않습니다.
브라우저 데이터를 지우면 기록도 사라지니, 설정 탭에서 주 1회 백업하세요.

## 계획 수정

운동 단계, 등급별 처방(`levels`), 단계 묶음(`tiers`), 집 운동 변형(`variants`·`levelVariants`), 진행표, 식단, 저녁 메뉴는 모두 `plan.js`에 있습니다. 이 파일만 고치면 됩니다.

## 폰에서 쓰기 (GitHub Pages)

1. 위 주소를 폰 브라우저에서 엽니다.
2. "홈 화면에 추가"를 누르면 앱처럼 열리고, 오프라인에서도 열립니다.
3. 이 저장소에 변경을 올리면 1~2분 뒤 자동으로 반영됩니다.
