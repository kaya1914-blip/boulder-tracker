# 볼더링 복귀 트래커

볼더링 복귀 4주 계획(트레이닝 + 식단)을 매일 따라가기 위한 개인용 모바일 웹앱입니다.

- **오늘**: 이번 주에 남은 세션 중 오늘 할 것을 추천합니다(요일 자유, 고강도 연속 방지). 주차에 맞춘 체크리스트와 그날 식단을 보여줍니다.
- **기록**: 아침 체중, 수면, 통증, 갈색 완등 개수, 흰색 도달 홀드, 행보드 단계, 풀업 횟수를 적습니다.
- **주간**: 체중 그래프(7일 평균, 목표선)와 조정 규칙 자동 판정, 다음 주 권장사항을 보여줍니다.
- **설정**: 목표값 수정, JSON 백업 내보내기/불러오기.

## 데이터

기록은 서버 없이 **그 기기의 브라우저(localStorage)에만** 저장됩니다. 저장소에는 기록이 올라가지 않습니다.
브라우저 데이터를 지우면 기록도 사라지니, 설정 탭에서 주 1회 백업하세요.

## 계획 수정

운동 단계, 진행표, 식단, 저녁 메뉴는 모두 `plan.js`에 있습니다. 이 파일만 고치면 됩니다.

## 폰에서 쓰기 (GitHub Pages)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 지정합니다.
3. 나온 주소를 폰 브라우저에서 열고 "홈 화면에 추가"를 누릅니다. 이후 오프라인에서도 열립니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다.
